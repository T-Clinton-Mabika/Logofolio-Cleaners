# Logofolio Cleaners Website

## Portfolio Piece

This is a website designed and built for a fictional cleaning service. The website serves to advertise their services and have their clients reachout to them for inquiries and scheduling an appoitnment.

## Tech Stack 💻

- **Framework:** Next.js (App Router)
- **Languages:** Typescript
- **Styling:** CSS

## Dependencies 📦

To install all dependencies open project directory in terminal and run

```bash
npm install
```

### Icons:

- **React Icons:**
  - Main library of icons used for the projects UI and sections.
  - To install use:
  ```bash
  npm install react-icons
  ```
- **Boxicons:**
  - Additional icon library to obtain icons not found in react-icons.
  - To install use:
  ```bash
  npm install @boxicons/react
  ```
